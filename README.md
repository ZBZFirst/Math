Sometimes you just need a simple, no thrills place to practice something simple.

Here is a webpage that links to a simple addition, simple subtraction, simple division and simple multiplication checker.

It provides the following items
-Save state for the visit
-A simple ratio of Correct to Incorrect
-No ID required or IP Logging attempted
-Open Source Code for Review

This is supposed to be intuitive to a 2nd grader and difficult for a 1st grader.
While also being accessible to other parents who are looking for something to make their kids do instead of Roblox.
